# Photo-Storage-Website
A web application that allows users to create a profile, log in, and 
securely store their photos online. Users can upload, view, edit, and 
delete their stored photos at any time. All user data and photo records 
are managed through a connected database.
## Tech Stack
- HTML
- CSS
- JavaScript
- PHP
- Bootstrap
- SQL Server (database)
## Features
- User registration and login
- Upload and store photos
- Edit photo details
- Delete stored photos
- Database tracks user accounts and stored photo records
